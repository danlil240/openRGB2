# OpenRGB2 icon

`openrgb2-icon.png` is the transparent master artwork for the OpenRGB2
abstract three-blade icon. `packaging/windows/OpenRGB2.ico` contains 16, 24, 32,
48, 64, 128, and 256 pixel versions for the application, tray, and desktop
shortcut. The existing Qt resource and Windows executable resource both
use that ICO file.

Created with the built-in image generation tool on 2026-09-29. Three
rounded blades use cyan, violet, and coral pink, with transparent space
between them. The bright mark is intended for light and dark backgrounds.
